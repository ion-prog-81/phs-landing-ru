Статический сайт: хаб-страница + 9 лендингов продуктовых линеек PHS Life Sciences на русском языке. Структура и визуальные материалы повторяют оригинальные страницы `phslifesciences.com/brand-technology/*`; тексты переведены и адаптированы, изображения и логотипы скопированы локально.

## Структура

```
index.html, *.html      — страницы
style.css               — общая вёрстка (адаптивная)
assets/img/             — изображения без текста (логотип, фото, продукт)
assets/img-text/        — изображения, на которых есть текст: оставлены как в оригинале,
                          собраны для последующего перевода (см. _TO-TRANSLATE.md)
```

## Как открыть

Просто откройте `index.html` в браузере. Для локального сервера:

```bash
cd ~/vault/Projects/Sites/phs-brand-landing
python3 -m http.server 8000
# http://localhost:8000
```

Внешних зависимостей, кроме Google Fonts (Inter/Manrope), нет. Перед офлайн-деплоем шрифты можно заменить на системные или положить локально.

## Тексты и картинки

- HTML-тексты переведены на русский по глоссарию `Projects/Suppliers/phs/glossary-ru.md` и согласованным формулировкам русского каталога PHS.
- Картинки с текстом **не переводились** — они лежат в `assets/img-text/` и используются на страницах как в оригинале. Список для перевода — `assets/img-text/_TO-TRANSLATE.md`.
- После перевода картинок достаточно заменить файлы с теми же именами (или обновить пути в HTML).

## QA: что проверено и какие расхождения с оригиналом

Проверка 16.11.2026: все 10 страниц, 0 битых изображений, горизонтального переполнения на 1440 px нет.

Исправлено в ходе вычитки:
- «Официальный представитель» → **«эксклюзивный дистрибьютор»** (по `Projects/Suppliers/phs/PHS_Eximin_Russia_Roadmap_v2.md`; статус «официальный представитель» нигде не подтверждён).
- «Девять технологических платформ» → **«девять продуктовых линеек»**: на сайте PHS говорится о пяти технологических платформах, а в меню девять продуктовых страниц.
- VitaQ Duo: приведены реальные преимущества и форматы (таблетки, капсулы, порошки, саше), исправлено 600 IU → **600 МЕ**, структура «проблемы → преимущества → состав/форматы» перестроена.
- Crea-Q: убрано выдуманное применение «напитки с электролитами», разделены батончики и порошковые смеси, убраны англицизмы (overage, blends, chewable).
- UniQ-Coat: добавлены две недостающие категории портфеля (прочие ингредиенты, подсластители), раскрыт NAC.
- NeoSphere: смягчена формулировка о всасывании/биодоступности — преимущества требуют подтверждения для конкретного продукта, как в оригинале.
- Терминология: «формуляция» → «рецептура», «чистая этикетка», «микрогранулы», «жевательные мармеладки», UHT, «избыточная закладка» — по глоссарию.

Расхождения/аномалии исходного сайта PHS:
- **FusiMelt**: страница на сайте PHS фактически дублирует CleanXtend (тот же заголовок и текст). Лендинг собран по русскому каталогу PHS — подкислители для кондитерских изделий. Отдельного фирменного визуала FusiMelt на сайте нет.
- **ThermoSpheres**: блок FAQ на странице PHS содержит вопросы Crea-Q (копипаст). В лендинге FAQ составлен по содержанию ThermoSpheres.
- **VitaQ Duo**: на сайте PHS написание плавает — «VitaQ® Duo» и «VitaQ Duo®». В лендинге унифицировано: **VitaQ Duo®**.
- **Vita-Q**: раздел «Enhancing Nutritional Delivery» переведён как четыре карточки (срок хранения, усвоение, высвобождение, гибкость рецептур).
- Все числовые данные (3,05×, ~90% за 120 дней при pH 4,0, 600 МЕ, 55 мкг, 10/20 мг) сверены с англоязычными страницами и русским каталогом.

Перед публикацией всё равно нужно подтвердить у PHS: актуальное наличие продуктов, концентрации и спецификации. В текстах это отмечено.
